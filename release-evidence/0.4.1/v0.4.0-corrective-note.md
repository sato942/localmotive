## Proposed correction for Localmotive 0.4.0

This draft does not modify the published release.

The 0.4.0 release notes used `Supported` for three configurations backed only by direct `llama.cpp` L2 evidence.

Those records did not contain a complete Localmotive product run.

Read the three rows as **direct runtime evidence only**, not product-support qualification:

- Windows 11 x64, AMD Ryzen 9 9950X3D, CPU;
- Windows 11 x64, NVIDIA GeForce RTX 5090, driver 610.74, CUDA 13.3;
- Windows 11 x64, NVIDIA GeForce RTX 5090, driver 610.74, Vulkan.

The `Windows 10/11 x64` statement described the intended product scope.

The 0.4.0 evidence did not qualify Windows 10 or complete clean-account installer testing.

The 0.4.0 source checks and local direct-runtime smoke checks passed as recorded.

The release did not run `scripts/verify_040.mjs` against the published package before publication.

A later audit ran `node scripts/verify_040.mjs 10042` against the published portable executable.

That later audit returned a nonzero result.

Do not treat the published installer, portable, upgrade, cancellation, restart, or uninstaller behavior as verified.

The published artifacts remain unchanged for auditability.

Review this correction before editing the public 0.4.0 release.
